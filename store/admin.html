Users

Who can open this admin on this computer, and what each of them is allowed to change.

What these accounts actually do. They control what each person sees and can change inside this admin, so a staff member cannot accidentally rewrite your prices or your Our Story page. That is worth having.

They are not website security. Anyone who can copy this folder, or open admin.html in Notepad, can work around them. Passwords are stored hashed, never as plain text, and never leave this computer — but do not put admin.html on a public server, and do not reuse a password here that you use anywhere else.

Stored on this computer only, never in any file that goes online. Make one at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Give it access to this one repository, and set Contents to Read and write.

Put the whole website online

Use this the first time, and any time I send you new files. Press Choose and pick your “Upload to web” folder — the whole folder, not the files inside it. Everything in it goes up: index.html, style.css, script.js and the photos, each in the right place.

Your products and prices are taken from this admin as you see them now, not from the old store-data.js in the folder. admin.html is never sent, whatever you pick.

Publish your changes

Day to day, once the website is up. Sends your products, prices and text — the shop's own files stay as they are. The website takes about a minute to catch up afterwards.

Recovery code

This is the only way back into this account if the password is forgotten. Write it down or save the file somewhere safe — a notebook, or a note on your phone.

It is shown once and never again. Nobody can look it up later, not even you — only a hashed version is stored. If both the password and this code are lost, an Owner has to reset the account from the Users tab.
